# 开关机相关功能的文件结构与调用关系

## 一、涉及的主要文件

| 文件路径                             | 层级     | 职责                         |
| ------------------------------------ | -------- | ---------------------------- |
| `ui/control_panel.py`                | UI层     | 提供开关机相关按钮和信号定义 |
| `ui/main_window.py`                  | 控制器层 | 处理信号，创建查询线程       |
| `ui/query_thread.py`                 | 线程层   | 异步执行查询任务             |
| `business/device_monitor_service.py` | 业务层   | 实现开关机核心逻辑           |
| `service/tool_service.py`            | 工具层   | 提供SSH/ADB/PSCP命令执行     |

## 二、调用关系链

```
┌─────────────────────┐     信号触发     ┌─────────────────────┐
│   control_panel.py  │ ────────────────>│    main_window.py   │
│  (UI按钮、信号定义)   │                 │  (信号处理、线程管理) │
└─────────────────────┘                 └─────────────────────┘
                                                    │ 创建线程
                                                    ▼
┌─────────────────────┐     调用方法     ┌─────────────────────┐
│    tool_service.py  │ <───────────────│ device_monitor_service.py │
│ (SSH/ADB/PSCP执行)   │                 │   (开关机业务逻辑)     │
└─────────────────────┘                 └─────────────────────┘
                                                    ▲
                                                    │ 调用
                                      ┌─────────────────────┐
                                      │    query_thread.py   │
                                      │   (异步查询执行)     │
                                      └─────────────────────┘
```

## 三、各功能的具体调用路径

### 1. 开关机初始化 (`count_init`)

**调用链**：

```
control_panel.query_count_init_button.clicked
    → main_window.query_selected("count_init")
        → QueryThread(query_type="count_init")
            → DeviceMonitorService.count_init_setting()
                → ToolService.adb_push_file() / pscp_push_file()
                → ToolService.ssh_execute_command()
```

**功能说明**：推送boot_counter.sh脚本和初始化配置文件，创建swich_counter_flag标记

### 2. 开关机检查 (`sum_switch`)

**调用链**：
```
control_panel.query_sum_switch_button.clicked
    → main_window.query_selected("sum_switch")
        → QueryThread(query_type="sum_switch")
            → DeviceMonitorService.sum_switch_count()
                → ToolService.ssh_execute_command("wc -l ...")
            → DeviceMonitorService.switch_log_output() (可选)
                → ToolService.adb_pull_file() / pscp_pull_file()
```

**功能说明**：读取swich_counter.csv和network_counter.csv统计开关机次数，可选导出日志

### 3. 清除开关机日志 (`clean_switch`)

**调用链**：
```
control_panel.query_clean_switch_button.clicked
    → main_window.query_selected("clean_switch")
        → QueryThread(query_type="clean_switch")
            → DeviceMonitorService.clean_switch_log()
                → ToolService.ssh_execute_command("rm -rf ...")
```

**功能说明**：删除swich_counter.csv、network_counter.csv及相关日志目录

### 4. 导出开关机日志 (在sum_switch中触发)

**调用链**：
```
QueryThread(query_type="sum_switch")
    → DeviceMonitorService.switch_log_output()
        → ToolService.adb_pull_file()  (Android系统)
        → ToolService.pscp_pull_file() (Linux系统)
```

**功能说明**：将设备上的日志文件拉取到本地`./switch_log/{device_id}/`目录

## 四、文件职责详细说明

### UI层 - control_panel.py
- 定义三个按钮：`query_count_init_button`、`query_sum_switch_button`、`query_clean_switch_button`
- 通过`query_selected_clicked`信号传递操作类型
- 在监控运行时禁用这些按钮

### 控制器层 - main_window.py
- 接收`query_selected_clicked`信号
- 创建`QueryThread`线程执行异步查询
- 维护`query_count`计数器和`switch_log_file`日志文件句柄

### 线程层 - query_thread.py
- 根据`query_type`调用不同的业务方法
- 处理系统类型判断（Android/Linux）
- 通过信号返回结果或错误

### 业务层 - device_monitor_service.py
- **`count_init_setting()`**：根据设备类型推送不同的脚本和配置
- **`sum_switch_count()`**：统计CSV文件行数获取开关机次数
- **`clean_switch_log()`**：删除日志文件和目录
- **`switch_log_output()`**：将日志拉取到本地

### 工具层 - tool_service.py
- **SSH命令**：`ssh_execute_command()`
- **ADB命令**：`adb_push_file()`、`adb_pull_file()`、`adb_disconnect()`
- **PSCP命令**：`pscp_push_file()`、`pscp_pull_file()`

## 五、关键数据流向

```
用户点击按钮
    ↓
信号传递操作类型
    ↓
创建查询线程
    ↓
根据设备类型选择执行路径
    ↓
调用ToolService执行命令
    ↓
返回结果到主线程
    ↓
更新UI显示结果
```
